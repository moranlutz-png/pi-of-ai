These rules are sent with every request, so they take up room in the context window. Baking them into the weights instead is what Bake will do.

Base vs baked

The same request goes to both models with no system prompt at all. The base model has never seen your rules, so it ignores them. The baked one obeys — not because it is told to, but because the rules are in its weights.

About

            
What this is, and why it exists.

            
Runtime: wllama (llama.cpp compiled to WebAssembly). On a locked-down school Chromebook the browser is the one runtime that's never disabled — so this app loads a quantized GGUF and runs inference entirely on-device, offline.

            
It's the Chromebook delivery target for the Rules-Baker: the "Raspberry Pi of AI" — cheap, hackable, private, and it runs on nearly any computer. Models can be baked with your own house-style rules and shared through the Library.

            
Runtime engine: wllama on GitHub ↗
