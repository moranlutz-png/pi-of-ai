# Pi-of-AI · Rules-Baker SFT dataset

Synthetic supervised-fine-tuning data for **[Pi-of-AI / Rules-Baker](https://github.com/moranlutz-png/pi-of-ai)**,
generated **fully locally** against an OpenAI-compatible teacher (Ollama running
Qwen2.5-Coder).

Each example is a chat-format `messages` record. Two kinds:

- **positive** — an ordinary coding request → rule-compliant code.
- **revision** — rule-violating code → corrected code (teaches self-repair).

**The whole trick:** the teacher *saw* the house-style rules when writing the
target code, but the stored prompt has the rules **stripped out**. A model trained
on this learns to obey the rules *silently*, keeping the inference-time context
window clean.

## Provenance & honesty

- Generated by `rules_baker/data_gen/generate_dataset.py`, which hard-gates every
  example: `ast.parse` validity, min-length, near-duplicate dedup, retry-on-reject,
  and a leak-proof train/eval seed split. Rejections are counted, never dropped
  silently.
- Small and evolving — this is an early, growing set, not a benchmark corpus.
  Regenerate or extend it from the seeds in the repo.
