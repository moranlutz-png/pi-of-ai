Scratch-Coder · Model Inspector

Every weight tensor in the from-scratch GPT, drawn from the architecture — one cell per tensor, sized by how many parameters it holds. This is a model small enough to see all the way through. It will never be a useful coder; that is the point.

loading…

Cell size is parameter count (√-scaled, or head.weight would drown every LayerNorm). Cell brightness is the tensor's weight spread (std) in the selected view. Difference is trained minus random — what training actually changed, which at four layers is less than you would guess, and not evenly. The striped cell is the causal mask: a fixed buffer, in the stack but never trained.

Embedding neighbourhoods

Each character placed where its learned embedding lands, projected to 2D — drawn as the character itself. Hover or click a glyph to see its nearest characters in the full 128-dimensional space, which is the check on the flat picture. A lightly-trained model may not have separated digits from letters from whitespace yet; mixed neighbours are the honest state of the model, not a rendering bug.

Live attention

Type a prompt; every head's attention over it is computed here in the browser — the whole thing, no sampling. Rows are layers, columns are heads; a bright cell (i, j) means position i attended to position j. It is lower-triangular because a token can only see itself and what came before.
